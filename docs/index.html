NO NETWORK

Local is the privacy feature

The core makes no network or filesystem calls. Evidence does not leave the operator’s machine unless the operator chooses to share the reviewed output.

NO MYSTERY MODEL

Rules can be challenged

A 429 maps to rate limiting; 5xx maps to an upstream failure; latency over 15 seconds maps to latency. The policy lives in readable Python and tests.

NO FALSE IDENTITY

A fingerprint is only a clue

The hash groups similar sanitized evidence. It is not proof of one root cause, and small evidence differences may split a real incident.

04

CASE OUTCOME

The value is a better next decision

WORKING HYPOTHESIS

Concurrency or retry pressure—not provider downtime.

The evidence supports a rate-limit investigation. It does not yet prove whether traffic volume, concurrency, or retry behavior caused it.

  1. 01Contain Honor the two-second Retry-After value.
  2. 02Correct Add bounded exponential backoff with jitter.
  3. 03Measure Capture concurrency and request volume.
  4. 04Escalate Send the request ID and sanitized reproduction if it persists.
“Useful support tooling should make uncertainty explicit, not decorate it.”— Emmanuel Asika, project author
FIELD NOTES

What Support Trace Analyzer does not do

  • It does not discover root cause or query provider telemetry.
  • It does not detect every possible secret or every category of PII.
  • It does not auto-submit tickets; a human owns the final handoff.
  • It does not replace logs, traces, metrics, or an incident platform.
