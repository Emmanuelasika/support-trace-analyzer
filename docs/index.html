The support workflow

Evidence in. Ambiguity out.

Every stage exists to shorten time-to-resolution while keeping customer data out of tickets and chat threads.

01

Validate the contract

Reject malformed status codes, latency, headers, and batch shapes with bounded operator errors.

tracekit validate evidence.jsonl
02

Redact recursively

Sanitize credential-shaped keys, bearer tokens, API keys, passwords, secrets, and email addresses at any depth.

tracekit redact evidence.json
03

Diagnose consistently

Classify auth, rate-limit, request-contract, latency, upstream, and unknown failures using inspectable rules.

confidence: high
04

Cluster safely

Group recurring failures using fingerprints that exclude request IDs and occurrence timestamps.

tracekit cluster evidence.jsonl
Architecture

A small, deliberate trust boundary.

Raw evidence never reaches a serializer. Redaction happens before diagnosis output exists.

No hidden inference

Classification logic is readable Python, versioned with tests, and suitable for review during an escalation.

No silent exfiltration

The application performs no network requests. Evidence remains on the operator’s machine.

No false certainty

Every result includes an explicit confidence level, observations, next actions, and escalation criteria.
